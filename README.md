🎧 Your music, your way. Musescape lets you curate playlists and explore your collection in style.
--------------------------------------------------------------------------------------------------------
Getting started

1.Fork the repository

2.Install dependencies: npm install

3.Start the frontend: npm run dev

4.Start the backend (in a separate terminal): node server.js
